# YouTube Audio to Text Telegram Bot

Асинхронный Telegram-бот на базе `aiogram 3` и `Faster-Whisper` для автоматического скачивания аудиодорожек из видеороликов YouTube (включая Shorts) и их последующей транскрибации в текст. 

Архитектура оптимизирована для стабильного инференса на CPU под высокими нагрузками (реализована промышленная очередь задач).

## ✨ Особенности системы

* **Высокоэффективный инференс (Faster-Whisper):** Использование движка на C++ с квантованием `int8` позволяет распознавать текст на CPU быстрее, чем оригинальный OpenAI Whisper на GPU, полностью исключая утечки памяти и проблемы с CUDA-драйверами.
* **Отказоустойчивая очередь задач (Concurrency Control):** Асинхронный семафор (`asyncio.Semaphore`) жестко ограничивает нагрузку на процессор. При одновременной отправке множества ссылок задачи выстраиваются в очередь, а пользователи видят свой текущий номер в пуле.
* **Сетевая изоляция (yt-dlp):** Встроенная защита от зависания сетевых сокетов, ограничение на количество попыток скачивания фрагментов и принудительный запрет на обработку плейлистов (`noplaylist`).
* **Автоматический чанкинг:** Текст раздается пользователю сплит-блоками до 4000 символов, обходя лимиты Telegram API на длину одного сообщения.
* **Безопасность данных:** Использование криптографически стойких токенов для именования временных файлов и гарантированная очистка диска (`finally` блок) при любом исходе транскрибации.

## 🛠 Технологический стек

* **Language:** Python 3.10+
* **Framework:** Aiogram 3.x (Asyncio)
* **Engine:** Faster-Whisper (Model: `base` / `int8`)
* **Media Downloader:** yt-dlp
* **Core Utility:** FFmpeg (для постобработки аудиоконтейнеров)

## 📋 Требования к окружению

Для работы бота в системе должен быть установлен **FFmpeg**. 

### Установка FFmpeg:
* **Windows (Conda):** `conda install ffmpeg -c defaults` (или скачайте бинарники с gyan.dev и добавьте в системный `PATH`).
* **Linux (Ubuntu/Debian):** `sudo apt update && sudo apt install ffmpeg`
* **macOS:** `brew install ffmpeg`

## 🚀 Быстрый старт

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/VA1650/YouTube-Audio-to-Text-Telegram-Bot.git
   cd YouTube-Audio-to-Text-Telegram-Bot 

2. Установите зависимости:
    Рекомендуется использовать изолированное окружение (Conda или venv):
    ```Bash

    pip install aiogram yt-dlp faster-whisper torch

3. Установите токен бота:
    Получите токен у @BotFather и задайте переменную окружения:

        Windows (CMD): set TELEGRAM_BOT_TOKEN=your_token_here

        Linux/macOS: export TELEGRAM_BOT_TOKEN="your_token_here"

4. Запустите бота:
    ```Bash

    python bot.py

## ⚙️ Конфигурация и лимиты

Основные лимиты зашиты в конфигурационной функции _download_audio внутри bot.py:

    match_filter: Максимальная длительность обрабатываемого видео ограничена 15 минутами (900 секунд) для предотвращения перегрузки CPU. При необходимости лимит можно изменить в коде.

    socket_timeout: Тайм-аут ожидания ответа от серверов YouTube — 15 секунд.
